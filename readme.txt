[size=16pt][b]AmazonAffiliate for ElkArte[/b][/size] (1.1.x / 2.0)
[hr]

o Adds your Amazon affiliate ID (tag) to every Amazon link in posts, personal messages, signatures, previews and search results.
o Expands Amazon short links (amzn.eu, amzn.to, a.co...) so they get your tag too.
o Marks affiliate links with rel="sponsored nofollow".
o Settings: Admin > Configuration > Addons Settings.
